SkylarLens Rental Co. - Panabo City website

Open index.html in any browser, or upload the folder to any web host
(Vercel, Netlify, GitHub Pages, cPanel hosting). It is one self-contained file.

Notes:
- Edit contact details, rates and photos by changing the text in index.html
  (rates and cameras are in the JSON block with id="site-default").
- The built-in admin panel (tap the logo 5 times, enter the PIN) saves changes
  only while the page is opened inside Claude as the owner. On your own hosting
  it opens but cannot save. Edit index.html directly there.
- Google Fonts need an internet connection; fallback fonts are used offline.

Update (video + features):
- New "Watch" section: promo video with thumbnail, 6 feature cards and a photo strip.
- Keep the "assets" folder next to index.html (video, thumbnail and photos live there).
- To change the video, replace assets/skylarlens-promo.mp4. To change the thumbnail,
  replace assets/video-thumb.jpg (same shape, 9:16).
- The back-to-top button now sits right above the "Ask SkylarLens" button.

Update (full admin panel):
Tap the logo 5 times and enter the PIN. Tabs: Site (logo, colors, headline, contact details,
footer, SEO), Cameras, Video (video, thumbnail, features), Photos, Sections (show/hide,
titles, menu labels, "Perfect for" cards, steps, banner), Chatbot (custom Q&A), Announcement,
Settings (change PIN, download updated page).
On your own hosting: edit, then Settings > "Download updated page" and upload it as index.html.
